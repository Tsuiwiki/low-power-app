# 低电量 · 精力防守 🔋

> 一款面向高内耗、周期性低能量人群的**低阻力精力管理与自我防守工具**。
> Local-First 纯本地存储 · 零依赖单文件 · PWA 离线可用

**在线体验**：https://tsuiwiki.github.io/low-power-app/

---

## 为什么做这个

传统习惯类 App 在低能量期会带来二次伤害：

| 痛点 | 本 App 的对策 |
|------|--------------|
| 断打卡后的「Streak 清零」挫败感 | **只加不减**的资产累计，永远没有连续天数 |
| 疲惫时面对宏大计划的执行瘫痪 | **不可思议微动作**——小到你无法拒绝（如「把双脚平放在地板上」） |
| 中断后不敢重新开始的断续焦虑 | **无损断点存盘**——一句话记录上下文，随时回来接着干 |
| 中途放弃时的「失败」提示 | 取消**不算失败**，静默记录一次「尝试启动」，随时欢迎再来 |

## 核心功能

- **🔋 动态电量路由**：滑动评估今日电量（1-100%），≤39% 自动切换低电量防守模式（暗夜 + 鼠尾草绿配色），≥40% 常规模式
- **🎲 微动作抽卡**：每次只推荐 1 个极小动作，换一个时严格排除当前项
- **▶ 1 分钟微启动**：极简全屏倒计时，基于绝对时间戳——锁屏/接电话切回来直接判定完成，绝不误判失败
- **🛋️ 纯休息模式**：20 分钟全黑倒计时 + 呼吸拍频底音（WebAudio），休息也是资产
- **📌 1 句话断点**：底部固定展示上次上下文（上限 50 字），强退重开依然在
- **📊 微资产统计**：累计完成 / 尝试启动 / 休息分钟，只加不减

## 设计红线

1. **严禁**连续打卡天数（Streak）
2. **严禁**任何形式的失败提示、红色警告、二次确认弹窗
3. **严禁**清空用户数据（存储异常时降级内存态， Schema 升级做字段合并）
4. 所有反馈使用柔和动效与低频音效，视觉降噪优先

## 本地运行

零依赖，双击即跑：

```bash
# 直接双击 index.html，或：
python -m http.server 8000
# 打开 http://localhost:8000
```

## 安装为手机 App（PWA）

用 HTTPS 访问（如 GitHub Pages 链接）后：

- **iPhone**：Safari → 分享 →「添加到主屏幕」
- **Android**：Chrome → 菜单 →「安装应用」

安装后全屏独立运行，首次加载后**完全离线可用**（Service Worker 缓存）。

## 技术栈

纯手写，无框架无构建：原生 HTML/CSS/JS + LocalStorage + Service Worker + Web Audio API + Screen Wake Lock API + Vibration API。

```
├── index.html      # 全部 UI + 逻辑（单文件核心）
├── manifest.json   # PWA 清单
├── sw.js           # Service Worker（缓存优先，离线秒开）
└── icon.svg        # 应用图标
```

## 数据与隐私

所有数据仅存于**本机浏览器 LocalStorage**（key: `low_power_app_state`），无任何网络请求、无统计、无追踪。换浏览器/设备数据不互通——这是特性，不是缺陷。
